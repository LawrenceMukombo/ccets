# ODK Form Definition (Cascading Selects)

This definition is designed for **KoboToolbox** or **ODK Build**.

## 1. Required Media Files
Before creating the form, upload these 5 files (generated by backend) to Kobo media settings:
1.  `regions.csv`
2.  `provinces.csv`
3.  `districts.csv`
4.  `facilities.csv`
5.  `equipment.csv`

## 2. XLSForm Content

Copy these tables into Excel sheets named **survey**, **choices**, and **settings**.

## 3. Webhook Configuration
In Kobo Project Settings > REST Services, add:
- **URL:** `https://ccets.lamtoninvestments.com/api/hooks/kobo/submission`
- **Trigger:** On Submission (JSON)
